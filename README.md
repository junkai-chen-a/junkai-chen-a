# Finance & Applied AI

Projects that explore how Python and language models can turn financial data into clear, checkable summaries.

## Featured project

[Finance AI Lab](https://github.com/junkai-chen-a/finance-ai-lab)

Start with a sample quarterly dataset, calculate revenue growth, operating margin, and free cash flow, then generate an earnings brief or a prompt for a language model.

The demo uses synthetic data and runs locally with Python. The repository includes the source code, sample CSV, and instructions to reproduce the results.
